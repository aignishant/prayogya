## One-line answer

Thirteen tests hold the plugin to charging calls rather than counting events, the refusal to being a
returned value rather than an exception, the log to recording how much and never what — and one of
them is the test whose absence let part 3.1's defect through.

## The idea

Two of the tests in this file exist because of the same morning.

Part 3.1's defect — a plugin that raised, an exception the framework wrapped, a whole branch of
`desk.decide` that went dead — was not caught by the hundred and eight tests that were green when it
shipped. Two tests failed, and neither was about the thing that broke. The branch that stopped
working had no test driving it to the limit; it had only ever been reached by a unit test that called
the budget directly.

So this file has `test_a_refused_claim_goes_pending_and_names_the_reason`, which takes a real claim,
gives it an allowance of zero, and asserts on the verdict. It would have failed on the raising
version. It is four lines.

That is worth stating plainly, because it is the most general lesson in this day: **a branch reached
only through a framework's extension point is a branch your unit tests do not reach.** Hooks are
where this bites hardest, because they run under someone else's control flow — the very reason to
use them.

The other shape in this file is testing what a callback **does not** do. A hook that logs is easy to
assert on; a hook that must not log the answer needs a test that reads the log and looks for the
answer's absence.

## The mechanism

The whole file, at `tests/test_hooks.py`:

```python
"""Callbacks and plugins: what runs around a call, what it may change, and what it must not do.

Two levels are tested separately because they fail separately: the plugin sees every agent and is
registered once on the runner, and the agent callback sees one agent and is a field on it.
"""

from __future__ import annotations

import asyncio
import json
from collections.abc import AsyncGenerator
from contextlib import asynccontextmanager

import pytest
from google.adk.agents import Agent
from google.adk.models.base_llm import BaseLlm
from google.adk.models.llm_request import LlmRequest
from google.adk.models.llm_response import LlmResponse
from google.adk.sessions import InMemorySessionService
from mcp import Client

from claims_desk import boundary, desk, hooks, sessions, workflow
from claims_desk.agents import classifier
from claims_desk.store import Store
from claims_desk.util.budget import Budget
from claims_mcp import tools
from claims_mcp.server import server

DESCRIPTION = "the flexible hose let go overnight"


@pytest.fixture(autouse=True)
def _in_process(tmp_path, monkeypatch):
    monkeypatch.setattr(tools.store, "claims", tmp_path / "claims")
    monkeypatch.setattr(sessions, "service", InMemorySessionService())

    @asynccontextmanager
    async def connected():
        async with Client(server) as client:
            yield client

    monkeypatch.setattr(boundary, "connected", connected)
    return tmp_path


@pytest.fixture()
def budgeted():
    """Register a budget for the duration of one test, the way the workflow does for one claim."""
    budget = Budget(limit=desk.CALLS_PER_NOTIFICATION, label="one test")
    token = hooks.current_budget.set(budget)
    refused = hooks.refusals.set([])
    yield budget
    hooks.refusals.reset(refused)
    hooks.current_budget.reset(token)


def test_the_plugin_charges_the_call_rather_than_counting_the_events(budgeted) -> None:
    """Day 10 counted what a model said. This counts what the desk pays for."""
    asyncio.run(sessions.turn(classifier.build(), "FNOL-4471", DESCRIPTION))
    assert budgeted.spent == 1
    assert budgeted.by == {"classifier": 1}


def test_the_plugin_charges_every_agent_by_its_own_name(budgeted) -> None:
    asyncio.run(sessions.turn(classifier.build(), "FNOL-4471", DESCRIPTION))
    asyncio.run(
        sessions.turn(
            workflow.correspondence(),
            "FNOL-4471",
            "Claim: FNOL-4471\nReason: missing_photo_reference",
            state={"claim": "FNOL-4471"},
            thread="correspondence",
        )
    )
    assert budgeted.by == {"classifier": 1, "letter_writer": 1}


def test_a_refused_call_is_replaced_rather_than_raised() -> None:
    """A callback must not raise for an ordinary condition. Being over budget is ordinary."""
    budget = Budget(limit=1, label="one call only")
    token = hooks.current_budget.set(budget)
    refused = hooks.refusals.set([])
    try:
        said, _events = asyncio.run(sessions.turn(classifier.build(), "FNOL-4471", DESCRIPTION))
        assert said != ""
        again, _events = asyncio.run(sessions.turn(classifier.build(), "FNOL-4471", DESCRIPTION))
        assert again == hooks.REFUSED
        assert hooks.refusals.get() == ["classifier"]
    finally:
        hooks.refusals.reset(refused)
        hooks.current_budget.reset(token)
    assert budget.by == {"classifier": 1}


def test_a_refused_claim_goes_pending_and_names_the_reason() -> None:
    """The desk reads the refusal as a returned value, because a plugin does not raise."""
    queue = {n.id: n for n in Store().notifications()}
    verdict = asyncio.run(desk.decide(queue["FNOL-4477"], Budget(limit=0, label="nothing")))
    assert verdict.outcome == desk.PENDING
    assert verdict.waiting_for == workflow.OVER_BUDGET


def test_the_plugin_runs_without_a_budget_registered() -> None:
    """Outside a unit of work there is nothing to charge, and nothing should break."""
    assert hooks.current_budget.get() is None
    said, _events = asyncio.run(sessions.turn(classifier.build(), "FNOL-4471", DESCRIPTION))
    assert json.loads(said)["loss_type"] == "escape-of-water"


def test_the_letter_writer_refuses_a_request_carrying_the_description(budgeted) -> None:
    """The second lock. Day 9 separated the conversations; this refuses the words themselves."""
    letter = asyncio.run(
        workflow.run_correspondence(
            "FNOL-4471",
            "missing_photo_reference",
            "a photograph of the damage",
            budgeted,
            forbidden="photograph",
        )
    )
    assert letter == ""
    # And it cost three drafts. The plugin charges before the agent callback refuses, and the
    # house style refuses an empty draft, so the loop goes round its full bound. A guaranteed
    # refusal is the one case the repair loop cannot help, and it pays anyway.
    assert budgeted.by == {"letter_writer": 3}


def test_the_same_letter_is_written_when_nothing_is_forbidden(budgeted) -> None:
    letter = asyncio.run(
        workflow.run_correspondence(
            "FNOL-4471",
            "missing_photo_reference",
            "a photograph of the damage",
            budgeted,
            forbidden=DESCRIPTION,
        )
    )
    assert "photograph" in letter


def test_the_queue_still_produces_what_the_brief_promised(_in_process) -> None:
    """Every letter now passes through two callbacks, and the twelve claims are unchanged."""
    counts = asyncio.run(desk.run_queue())
    assert counts == {"fast-track": 4, "deficiency": 8, "pending": 0}
    records = [
        json.loads(path.read_text(encoding="utf-8"))
        for path in sorted((_in_process / "claims").glob("*.json"))
    ]
    assert len(records) == 12
    assert len([r for r in records if "letter" in r]) == 8


class Unreachable(BaseLlm):
    """A stand-in that fails the way a provider outage does."""

    model: str = "scripted/unreachable"

    async def generate_content_async(
        self, llm_request: LlmRequest, stream: bool = False
    ) -> AsyncGenerator[LlmResponse, None]:
        raise RuntimeError("the provider was unreachable")
        yield  # pragma: no cover - never reached, and required to make this a generator


def test_the_error_hook_records_the_failure_and_does_not_swallow_it(budgeted) -> None:
    """Returning a response from `on_model_error_callback` would turn an outage into an answer."""
    agent = Agent(
        name="classifier",
        model=Unreachable(),
        description="Fails.",
        instruction="Anything.",
    )
    with pytest.raises(RuntimeError) as raised:
        asyncio.run(sessions.turn(agent, "FNOL-9999", "anything at all"))
    assert "the provider was unreachable" in str(raised.value)
    assert budgeted.by == {"classifier": 1}


def test_a_failed_call_is_still_charged(budgeted) -> None:
    """`before_model_callback` runs before the failure, so the attempt is paid for.

    That is the honest accounting: a provider that raises has usually still been contacted, and a
    budget that only counts successes cannot bound a retry loop.
    """
    agent = Agent(
        name="classifier", model=Unreachable(), description="Fails.", instruction="Anything."
    )
    for _ in range(2):
        with pytest.raises(RuntimeError):
            asyncio.run(sessions.turn(agent, "FNOL-9999", "anything at all"))
    assert budgeted.spent == 2


def test_the_plugin_logs_the_tool_calls_the_boundary_makes(capsys) -> None:
    """Tool hooks fire for tools an agent calls. This desk's boundary calls are not those."""
    asyncio.run(boundary.fetch_policy("PH-88213"))
    logged = capsys.readouterr().err
    assert "boundary.fetch_policy" in logged
    assert "hooks.tool" not in logged


def test_a_refusal_in_one_run_does_not_reach_the_next() -> None:
    """The refusals list is a context variable with `None` as its default, on purpose."""
    assert hooks.refusals.get() is None
    budget = Budget(limit=0, label="nothing at all")
    token = hooks.current_budget.set(budget)
    refused = hooks.refusals.set([])
    try:
        asyncio.run(sessions.turn(classifier.build(), "FNOL-4471", DESCRIPTION))
        assert hooks.refusals.get() == ["classifier"]
    finally:
        hooks.refusals.reset(refused)
        hooks.current_budget.reset(token)
    assert hooks.refusals.get() is None


def test_what_the_plugin_writes_never_contains_what_was_said(budgeted, capsys) -> None:
    """The log records how much, never what. A log is retained; a claim's prose is not ours."""
    asyncio.run(sessions.turn(classifier.build(), "FNOL-4471", DESCRIPTION))
    lines = [
        json.loads(line)
        for line in capsys.readouterr().err.splitlines()
        if line.startswith("{") and '"hooks.model"' in line
    ]
    assert len(lines) == 1
    assert lines[0]["agent"] == "classifier"
    assert lines[0]["chars"] > 0
    assert "escape-of-water" not in json.dumps(lines[0])
```

**Line by line:**

- **The `_in_process` fixture is the same three lines as days 6, 8, 9 and 10.** Fifth file. The rep to
  extract it is in this day's brief and it should have been taken two days ago.
- `@pytest.fixture() def budgeted()` — **a fixture that registers a budget the way the workflow
  does**, including resetting both context variables afterwards. Without it every test would repeat
  four lines of `set` and `reset`, and one of them would forget the reset and poison the rest of the
  file.
- **The reset is after the `yield`, not in a `finally`.** Pytest runs fixture teardown even when a
  test fails; the three tests that manage the variables by hand use `try`/`finally`, because they are
  demonstrating the discipline the fixture hides.
- `test_the_plugin_charges_the_call_rather_than_counting_the_events` — **the name is the day.** One
  turn, one call, and `by == {"classifier": 1}`. Against this stand-in the number is the same one day
  10 produced; the difference is where it came from.
- `test_the_plugin_charges_every_agent_by_its_own_name` — two turns, two agents, **one budget**, and
  the breakdown names both. This is the assertion that would fail if the plugin charged the workflow
  rather than the node inside it.
- `test_a_refused_call_is_replaced_rather_than_raised` — **the day's central behavioural test.** A
  limit of one, two turns: the first answers, the second comes back as `hooks.REFUSED`. No
  `pytest.raises` anywhere in it, which is the point.
- `assert again == hooks.REFUSED` — **compared against the constant**, so a change to what a refusal
  looks like is a change in one place and this test follows it.
- `assert budget.by == {"classifier": 1}` **after** the refusal — **a refused call is not charged
  twice.** `Budget.spend` raised before recording, so the breakdown shows the one call that
  succeeded.
- `test_a_refused_claim_goes_pending_and_names_the_reason` — **the test part 3.1 was missing.** Four
  lines, a real claim, `Budget(limit=0)`, and two assertions on the verdict. It fails on the raising
  version with a `RuntimeError` instead of a pending verdict.
- `assert verdict.waiting_for == workflow.OVER_BUDGET` — **the constant again.** "Pending" is not
  enough: part 1.2's whole argument is that *why* it is pending decides what somebody does about it.
- `test_the_plugin_runs_without_a_budget_registered` — **asserts the plugin's early return.** It
  begins by asserting `current_budget.get() is None`, which is also a check that no earlier test in
  the file leaked its budget.
- `test_the_letter_writer_refuses_a_request_carrying_the_description` — **the agent callback**, and
  the assertion below it is the measured cost: `{"letter_writer": 3}`.
- **The comment above that assertion explains a number that looks wrong.** Three drafts for a letter
  that was never written. Without the comment, the next reader deletes the assertion as a mistake.
- `test_the_same_letter_is_written_when_nothing_is_forbidden` — **the negative control**, and it
  forbids the real description rather than nothing at all. A test that passed `forbidden=""` would
  prove only that the guard can be switched off.
- `test_the_queue_still_produces_what_the_brief_promised` — **the headline numbers, again.** Every
  letter now passes through a plugin hook and an agent callback, and twelve claims with eight letters
  is unchanged. This is the assertion that catches a hook that quietly changed an answer.
- `class Unreachable(BaseLlm)` with `raise` then `yield` — **the day-8 stand-in that fails**, and the
  unreachable `yield` is what makes the function an async generator. The comment says so, because it
  looks like dead code and is load-bearing.
- `test_the_error_hook_records_the_failure_and_does_not_swallow_it` — **the outage still reaches the
  caller.** If `on_model_error_callback` returned a response, this test would fail with "DID NOT
  RAISE", which is exactly the alarm you want for a hook that can invent answers during an outage.
- `test_a_failed_call_is_still_charged` — **two failures, two calls charged.** The docstring argues
  the case: a provider that raises has usually still been contacted, and a budget that only counts
  successes cannot bound a retry loop — which is day 15's problem, being paid for now.
- `test_the_plugin_logs_the_tool_calls_the_boundary_makes` — **a test that asserts an absence, and
  its name is a lie the docstring corrects.** `hooks.tool` does *not* fire for this desk's boundary
  calls, because those are made by this project's own client rather than by an agent calling a tool.
  Worth pinning: somebody will otherwise expect the plugin to see them.
- `test_a_refusal_in_one_run_does_not_reach_the_next` — **the `B039` lint rule, as a test.** It
  asserts `None` before, a list during, and `None` after. The lint rule catches the mutable default;
  this catches a caller that forgets to reset.
- `test_what_the_plugin_writes_never_contains_what_was_said` — **parses the log and looks for what
  should not be there.** `assert "escape-of-water" not in json.dumps(lines[0])` is the assertion part
  1.3's failure would break, and it is the only kind of test that can hold a privacy rule.
- `assert len(lines) == 1` — **one line per call**, which would also catch a hook accidentally
  registered twice.

## When it breaks

Make `after_model_callback` log the text — part 1.3's failure — and run the file:

```
FAILED tests/test_hooks.py::test_what_the_plugin_writes_never_contains_what_was_said
1 failed, 12 passed
```

One test. The letters are still right, the budget is still charged, the queue still produces twelve
claims and eight letters, and the only thing that objects is the test written specifically to object.

That is what a privacy assertion looks like, and it is worth noticing how unlike the rest of the file
it is. Every other test here says *this should happen*. This one says *this should not appear*, and a
test of that shape can only ever be as good as the string it looks for. It checks for
`escape-of-water` — the classifier's answer on this claim. It would not notice a hook that logged the
policyholder's description, or the policy number, or a letter.

The smallest fix is `chars` instead of `text`. The rule worth carrying: **an absence test is a
tripwire, not a proof.** It is worth having — it caught this — and it must not be mistaken for a
guarantee that nothing sensitive is logged. The guarantee, if you need one, is a logger that
allow-lists fields, which is the rep day 8 opened and this project still has not taken.

## In production

**What a senior writes instead.** The same thirteen, plus one that asserts the plugin is registered
at all — `test_the_plugin_charges…` covers it indirectly and would also fail for six other reasons.
What they would add beyond tests is a **counter on the refusal path**: the number of claims refused
for budget this week, which is the difference between a limit that protects and a limit that quietly
stops the desk working.

**What degrades at scale.** Thirteen tests for two hooks is proportionate. The shape that does not
scale is the `budgeted` fixture's blast radius: every test that uses it shares one process-wide
context variable, so a test that spawns a task and does not await it can leave a budget registered
for whatever runs next. It has not happened here, and it is the kind of thing that appears the first
time somebody adds a concurrency test — which for this desk would be the `asyncio.gather` version of
the queue in day 10's brief.

**The review comment.** *"Every test here registers the budget through the fixture except three, which
do it by hand with `try`/`finally`. If that is deliberate, say so in a comment; if it is not, use the
fixture, because the next person will copy whichever one they see first."*

**The interview question.** *"Write me a test that a piece of cross-cutting code does not log
something. Then tell me what that test does not prove."*
