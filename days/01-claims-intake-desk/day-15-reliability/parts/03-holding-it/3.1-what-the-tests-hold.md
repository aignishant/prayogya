## One-line answer

Nineteen tests hold the waiting policy, the retry, the budget guard, the idempotency key and the
escalation — and **not one of them sleeps**, because every test that involves waiting passes its own
`sleep` and inspects the schedule instead of living through it.

## The idea

A reliability suite that waits is a reliability suite nobody runs.

Three attempts with waits of one and two seconds is three seconds per test, and there are seven tests
here that involve a retry. Twenty-one seconds to check a policy that is entirely arithmetic — so
those tests get marked slow, then skipped, then deleted, and the waiting policy ends up being the
part of the system with no tests at all.

Day 1 saw that coming. `backoff.retry` took a `sleep` parameter on the first day this project had
code, with the reason in its docstring: *a test should watch the schedule rather than live through
it.* Every test in this file uses that, through a small `Watch` class that records what it was asked
to wait rather than waiting.

The consequence is worth stating plainly, because it is the whole reason the file is thorough. **The
waits are assertable.** `watch.waited == [1.0, 2.0]` is a stronger statement than "it eventually
succeeded", and it costs nothing, so the tests check things a slower suite would never bother with:
that a capped interval is capped, that a budget-blocked retry waits zero times, that a provider's
interval is used on *every* attempt rather than only the first.

The one thing this arrangement cannot check is that the real `asyncio.sleep` is called correctly when
no `sleep` is passed. That is a genuine gap, it is one line of production code, and naming it is
better than pretending the suite covers it.

## The mechanism

The whole file, at `tests/test_reliability.py`:

```python
"""Reliability: what is retried, how long it waits, what it refuses to do twice, and when it stops.

No test here sleeps. Every one that involves waiting passes its own `sleep` and inspects the
schedule, which is the arrangement day 1's `backoff.retry` was built for on the first day of this
project.
"""

from __future__ import annotations

import asyncio
import json
import pathlib
from contextlib import asynccontextmanager

import pytest
from google.adk.sessions import InMemorySessionService
from mcp import Client

from claims_desk import boundary, desk, models, reliability, sessions
from claims_desk.agents import classifier
from claims_desk.scripted import ScriptedTransient
from claims_desk.util.backoff import Transient
from claims_desk.util.budget import Budget
from claims_mcp import tools
from claims_mcp.server import server


@pytest.fixture(autouse=True)
def _in_process(tmp_path, monkeypatch):
    monkeypatch.setattr(tools.store, "claims", tmp_path / "claims")
    monkeypatch.setattr(sessions, "service", InMemorySessionService())

    @asynccontextmanager
    async def connected():
        async with Client(server) as client:
            yield client

    monkeypatch.setattr(boundary, "connected", connected)
    return tmp_path


class Watch:
    """A sleep that records rather than waits."""

    def __init__(self) -> None:
        self.waited: list[float] = []

    async def __call__(self, seconds: float) -> None:
        self.waited.append(seconds)


# --- how long it waits ---------------------------------------------------------------------------


def test_the_schedule_is_day_ones_and_is_not_reinvented() -> None:
    assert reliability.WAITS == (1.0, 2.0)
    assert reliability.ATTEMPTS == 3
    assert len(reliability.WAITS) == reliability.ATTEMPTS - 1


def test_the_providers_own_interval_beats_our_arithmetic() -> None:
    assert reliability.wait_for(1, Transient("busy", retry_after=5)) == 5
    assert reliability.wait_for(1, Transient("busy")) == 1.0
    assert reliability.wait_for(2, Transient("busy")) == 2.0


def test_an_interval_long_enough_to_be_a_refusal_is_capped() -> None:
    """A provider asking for an hour is telling you to stop, not to wait."""
    assert reliability.wait_for(1, Transient("busy", retry_after=900)) == 30.0
    assert reliability.LONGEST_HONOURED_WAIT == 30.0


def test_an_attempt_past_the_schedule_reuses_the_last_wait() -> None:
    """Defensive: `attempts` is a parameter, and the schedule is one shorter than it."""
    assert reliability.wait_for(9, Transient("busy")) == reliability.WAITS[-1]


# --- what it retries -----------------------------------------------------------------------------


def test_a_transient_failure_is_retried_and_then_succeeds() -> None:
    attempts = {"n": 0}
    watch = Watch()

    async def busy_twice() -> str:
        attempts["n"] += 1
        if attempts["n"] < 3:
            raise Transient("the provider was busy")
        return "answered"

    got = asyncio.run(reliability.with_retry("classify", busy_twice, sleep=watch))
    assert got == "answered"
    assert attempts["n"] == 3
    assert watch.waited == [1.0, 2.0]


def test_when_the_attempts_run_out_it_raises_rather_than_substituting() -> None:
    watch = Watch()

    async def never_works() -> str:
        raise Transient("the provider was unreachable")

    with pytest.raises(reliability.Unavailable) as gone:
        asyncio.run(reliability.with_retry("classify", never_works, sleep=watch))
    assert gone.value.attempts == 3
    assert gone.value.what == "classify"
    assert "the provider was unreachable" in str(gone.value)
    assert watch.waited == [1.0, 2.0]


def test_only_a_transient_is_retried() -> None:
    """Anything else is a bug, and retrying a bug three times is three bugs."""
    attempts = {"n": 0}

    async def broken() -> str:
        attempts["n"] += 1
        raise ValueError("a real defect")

    with pytest.raises(ValueError):
        asyncio.run(reliability.with_retry("classify", broken, sleep=Watch()))
    assert attempts["n"] == 1


def test_a_retry_the_budget_cannot_pay_for_is_not_attempted() -> None:
    """A retry is another model call. Spending the last of an allowance to discover it is gone
    leaves nothing for the claim after this one."""
    attempts = {"n": 0}
    watch = Watch()

    async def always_busy() -> str:
        attempts["n"] += 1
        raise Transient("the provider was busy")

    with pytest.raises(reliability.Unavailable):
        asyncio.run(
            reliability.with_retry(
                "classify", always_busy, sleep=watch, budget_left=lambda: 0
            )
        )
    assert attempts["n"] == 1
    assert watch.waited == []


def test_a_budget_with_something_left_does_retry() -> None:
    attempts = {"n": 0}

    async def busy_once() -> str:
        attempts["n"] += 1
        if attempts["n"] == 1:
            raise Transient("the provider was busy")
        return "answered"

    got = asyncio.run(
        reliability.with_retry("classify", busy_once, sleep=Watch(), budget_left=lambda: 2)
    )
    assert got == "answered"
    assert attempts["n"] == 2


# --- through the real agent ----------------------------------------------------------------------


def test_a_busy_provider_recovers_on_the_second_attempt() -> None:
    """The stand-in refuses once with a `Retry-After`, then answers as the classifier would."""
    model = ScriptedTransient(fail_times=1, retry_after=0.5)
    watch = Watch()

    async def ask() -> str:
        agent = classifier.build(model=model, output_key="reading")
        said, _events = await sessions.turn(
            agent, "FNOL-4471", "the flexible hose let go overnight"
        )
        return said

    said = asyncio.run(
        reliability.with_retry("triage FNOL-4471", ask, sleep=watch)
    )
    assert json.loads(said)["loss_type"] == "escape-of-water"
    assert watch.waited == [0.5]


def test_a_provider_that_never_answers_leaves_the_claim_pending(_in_process, monkeypatch) -> None:
    """The whole point of the day: escalation, never a fabricated classification."""
    queue = {note.id: note for note in desk.Store().notifications()}

    async def instantly(seconds: float) -> None:
        return None

    # `desk.reliability` *is* the module, so the original has to be captured before it is
    # replaced — otherwise the replacement calls itself.
    original = reliability.with_retry

    def without_waiting(what, call, **kw):
        kw["sleep"] = instantly
        return original(what, call, **kw)

    monkeypatch.setattr(desk.reliability, "with_retry", without_waiting)
    monkeypatch.setattr(
        desk.workflow,
        "run_triage",
        lambda *a, **k: _always_busy(),
    )

    verdict = asyncio.run(desk.decide(queue["FNOL-4477"], Budget(limit=5, label="FNOL-4477")))
    assert verdict.outcome == desk.PENDING
    assert verdict.waiting_for == desk.UNAVAILABLE
    assert verdict.record is None
    assert not list((_in_process / "claims").glob("*.json"))


async def _always_busy():
    raise Transient("the provider was unreachable")


# --- what it refuses to do twice -----------------------------------------------------------------


def test_the_same_intended_write_has_the_same_key() -> None:
    first = reliability.idempotency_key("FNOL-4471", "fast-track", None, None)
    again = reliability.idempotency_key("FNOL-4471", "fast-track", None, None)
    assert first == again
    assert len(first) == 16


def test_a_different_decision_about_the_same_claim_has_a_different_key() -> None:
    """The half that matters: a key must not hide a real change."""
    fast = reliability.idempotency_key("FNOL-4471", "fast-track", None, None)
    deficient = reliability.idempotency_key("FNOL-4471", "deficiency", "injury_reported", None)
    with_letter = reliability.idempotency_key("FNOL-4471", "deficiency", "injury_reported", "Dear")
    assert len({fast, deficient, with_letter}) == 3


def test_a_repeated_write_lands_once(_in_process) -> None:
    key = reliability.idempotency_key("FNOL-4471", "fast-track", None, None)

    async def write_twice() -> tuple[dict, dict]:
        first = await boundary.record_decision("FNOL-4471", "fast-track", None, None, None, key)
        again = await boundary.record_decision("FNOL-4471", "fast-track", None, None, None, key)
        return first, again

    first, again = asyncio.run(write_twice())
    assert first["recorded"] is True
    assert "repeat" not in first
    assert again["recorded"] is True
    assert again["repeat"] is True
    assert len(list((_in_process / "claims").glob("*.json"))) == 1


def test_a_different_decision_under_a_new_key_is_refused(_in_process) -> None:
    """Not silently overwritten, and not silently accepted. A decided claim is decided."""

    async def write_then_change() -> dict:
        await boundary.record_decision(
            "FNOL-4471",
            "fast-track",
            None,
            None,
            None,
            reliability.idempotency_key("FNOL-4471", "fast-track", None, None),
        )
        return await boundary.record_decision(
            "FNOL-4471",
            "deficiency",
            "injury_reported",
            None,
            None,
            reliability.idempotency_key("FNOL-4471", "deficiency", "injury_reported", None),
        )

    refused = asyncio.run(write_then_change())
    assert refused["recorded"] is False
    assert refused["refused"] == "this claim already carries a different decision"


def test_a_write_without_a_key_is_still_accepted(_in_process) -> None:
    """Every call site in this desk passes one. The tool does not require it, so day 6's tests
    and anything written before day 15 keep working."""
    written = asyncio.run(boundary.record_decision("FNOL-4471", "fast-track"))
    assert written["recorded"] is True


def test_the_key_is_stored_beside_the_decision(_in_process) -> None:
    asyncio.run(desk.run_queue())
    stored = json.loads((_in_process / "claims" / "FNOL-4471.json").read_text(encoding="utf-8"))
    assert stored["idempotency_key"] == reliability.idempotency_key(
        "FNOL-4471", stored["outcome"], stored["reason"], stored.get("letter")
    )


def test_already_written_reads_the_store_and_not_a_cache() -> None:
    key = reliability.idempotency_key("FNOL-4471", "fast-track", None, None)
    assert reliability.already_written({"idempotency_key": key}, key) is True
    assert reliability.already_written({"idempotency_key": "something else"}, key) is False
    assert reliability.already_written(None, key) is False
    assert reliability.already_written({}, key) is False


# --- what this desk refuses to build -------------------------------------------------------------


def test_the_desk_has_no_fallback_model() -> None:
    """A claim decided by whichever model happened to be up is a claim whose record cannot say
    what decided it. Day 14 made that a property; this keeps it."""
    source = pathlib.Path(reliability.__file__).read_text(encoding="utf-8")
    # The decision is written down in the module that would have held the fallback chain.
    assert "There is no fallback model in here and that is deliberate." in source
    assert classifier.build().model.model != models.FALLBACK
    assert classifier.build().model.model != models.PRIMARY
```

**Line by line:**

- **The docstring's first line is the constraint**: no test here sleeps. Somebody adding a test to
  this file needs to know that before they write `await asyncio.sleep`.
- `class Watch` **with an async `__call__`** — a callable object rather than a function, so the
  recording and the interface live together and a test reads `watch.waited` rather than closing over
  a list.
- **Four tests about the waiting policy, none of which runs a retry.** `wait_for` was extracted for
  exactly this: the policy is six lines and every branch of it gets a test that is one assertion.
- `assert reliability.WAITS == (1.0, 2.0)` **and** `assert len(reliability.WAITS) == ATTEMPTS - 1` —
  the second is the relationship, not the values. Change `ATTEMPTS` and the first fails loudly while
  the second explains why.
- `test_an_interval_long_enough_to_be_a_refusal_is_capped` — **the name carries the argument.** A
  test called `test_retry_after_is_capped` would say what happens; this says why it should.
- `test_an_attempt_past_the_schedule_reuses_the_last_wait` — **a defensive branch, tested.** Nothing
  in this project passes a larger `attempts`, and the day it does, an `IndexError` mid-outage is the
  worst possible moment to find out.
- `test_a_transient_failure_is_retried_and_then_succeeds` — **three assertions**: the answer, the
  number of attempts, and the schedule. The third is the one only this arrangement makes possible.
- `test_when_the_attempts_run_out_it_raises_rather_than_substituting` — **the name is the day.** It
  asserts on `gone.value.attempts` and `.what` rather than on the message, which is why part 1.1 kept
  them as attributes.
- `test_only_a_transient_is_retried` — **`ValueError` tried exactly once.** Retrying a defect three
  times is three defects and a slower failure, and this is the assertion that keeps `except
  Transient` from widening to `except Exception` during an incident.
- `test_a_retry_the_budget_cannot_pay_for_is_not_attempted` — **`attempts["n"] == 1` and
  `watch.waited == []`.** Both, because "did not retry" and "did not wait" are separately worth
  knowing: a version that skipped the call but slept anyway would pass the first.
- `test_a_budget_with_something_left_does_retry` — **the control.** Without it, a guard that always
  refused would pass the test above and nothing else would notice.
- `test_a_busy_provider_recovers_on_the_second_attempt` — **the first test that runs a real agent**,
  through `sessions.turn`, the plugin, the schema and day 13's validation. `ScriptedTransient` fails
  once with a `Retry-After` of 0.5 and then falls through to the real classifier.
- `assert json.loads(said)["loss_type"] == "escape-of-water"` — **a recovered retry produces the same
  answer as a first-attempt success**, which is the property that makes retrying safe here and is
  worth asserting rather than assuming.
- `assert watch.waited == [0.5]` — **the provider's interval, not ours.** Day 1's schedule would have
  said 1.0.
- `test_a_provider_that_never_answers_leaves_the_claim_pending` — **the escalation, end to end**, and
  the four assertions are the four things part 2.1 promises: pending, the right `waiting_for`, no
  record, and nothing written to the claims directory.
- `original = reliability.with_retry` **captured before the patch** — with a comment saying why.
  `desk.reliability` *is* the module, so a replacement that called `reliability.with_retry` would call
  itself. That was a real `RecursionError` while this file was being written.
- `test_the_same_intended_write_has_the_same_key` **and**
  `test_a_different_decision_about_the_same_claim_has_a_different_key` — **the two halves of the
  property**, and the second is the one that stops a key hiding a change. `len({fast, deficient,
  with_letter}) == 3` asserts all three differ in one line.
- `test_a_repeated_write_lands_once` — **four assertions and a file count.** The first write has no
  `repeat` field, the second has `repeat: True`, both report `recorded: True`, and there is one file.
- `test_a_different_decision_under_a_new_key_is_refused` — **not overwritten and not accepted.** The
  message is asserted by equality, because it is the sentence an operator will read.
- `test_a_write_without_a_key_is_still_accepted` — **the migration, tested.** Every call site in this
  desk passes a key; the tool does not require one, so day 6's tests and every claim written before
  today keep working.
- `test_the_key_is_stored_beside_the_decision` — **recomputes the key from the stored record** and
  asserts it matches. That is what makes `already_written` able to ask the store.
- `test_already_written_reads_the_store_and_not_a_cache` — **four cases including `None` and `{}`**,
  because "no record" and "an empty record" arrive from different places and both mean not written.
- `test_the_desk_has_no_fallback_model` — **an absence test, in day 11's sense**, and it asserts on
  the decision rather than only on the code: the sentence that records the decision is in the module,
  and the classifier is pinned to neither the primary nor the fallback because it runs a stand-in.

**Line by line:**

- **Nineteen tests in 2.25 seconds**, of which seven involve a retry that would otherwise have waited
  three seconds each. The suite is roughly ten times faster than the thing it tests.
- **Two of them run a real agent turn**, which is where most of those 2.25 seconds go.

## When it breaks

Make `Watch` actually wait — two lines, and it is what removing the `sleep` parameter would amount
to, since every caller in production passes nothing:

```
19 passed in 10.12s
```

Verbatim, from this project. Nothing fails. Every assertion still holds, the schedule is still right,
and the file takes **ten seconds** instead of 2.25 — about four and a half times longer, for a suite
that checks arithmetic.

That is the failure, and it is a failure even though it is green. A suite that takes ten seconds to
check arithmetic is a suite somebody marks `slow`, and the tests that get marked slow are the ones
that stop running — which means the waiting policy, the budget guard and the escalation lose their
tests in the order they were written.

Notice which assertions would have to go with it. `watch.waited == [1.0, 2.0]` is not merely slow
without the parameter; it is **impossible**. There is nothing to inspect. The best available
replacement is measuring elapsed time and asserting it is roughly three seconds, which is flaky, says
nothing about the individual waits, and cannot distinguish "waited 1 then 2" from "waited 3 then 0".

And ten seconds is the *optimistic* figure. It is what this file costs when the waits are day 1's
1 and 2. A production schedule with a base of five seconds, or a fourth attempt, multiplies it
again — and the tests that would have caught a bad schedule are the first ones to go.

The smallest fix is keeping the parameter. The general rule is the one day 1 acted on before it had a
reason to: **anything that makes a system wait must accept its waiting as a parameter**, because
otherwise every test of that system is a test that waits, and waiting tests get deleted.

## In production

**What a senior writes instead.** The same suite, plus one test that does *not* pass a `sleep` and
asserts only that a single retry with a tiny interval completes — closing the gap this arrangement
leaves, which is that the real `asyncio.sleep` is never exercised. One test, a few milliseconds, and
it covers the one line the rest of the file cannot.

**What degrades at scale.** Nineteen tests is proportionate for one policy module. What grows badly
is the end-to-end pair: both of them run a real agent turn, and a project that adds an end-to-end
reliability test per failure mode ends up with a suite dominated by them. The shape that survives is
the one this file already has — most assertions against `wait_for` and `with_retry` directly, and a
small number through the whole stack to prove the wiring.

**The review comment.** *"`test_a_provider_that_never_answers_leaves_the_claim_pending` monkeypatches
`desk.workflow.run_triage` and `desk.reliability.with_retry`. That is two patches to test one branch,
and it will break the next time either module is reorganised. Inject the failure at the model instead
— `ScriptedTransient(fail_times=99)` — and patch nothing."*

**The interview question.** *"Write me a test for exponential backoff that runs in under a
millisecond. Then tell me what your test cannot prove."*
