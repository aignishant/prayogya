## One-line answer

Eighteen tests hold two agents to their separate remits, hold the letter writer out of the
classifier's conversation, hold the pair of them to one allowance of three — and one of them proves
the framework's delegation works, so that not using it stays a decision rather than an omission.

## The idea

When a second person joins the counter, the checks change shape. Nobody re-checks that a letter can
be written. What gets checked is the **seam**: that the two jobs are still separate, that neither has
quietly acquired the other's information, and that the pair of them together costs what the
department said it would.

Two of the tests in this file exist because of something that happened while the day was being
built. Part 3.1's leak passed every test that existed at the time — the letters were right, the
counts were right, nothing raised — and the only way it could have been caught is a test that asserts
on **what an agent was given** rather than on what it produced. So there is now one.

And one test does something that looks like waste. It builds two agents that have nothing to do with
claims, wires them with `sub_agents`, and asserts that a transfer happens. Nothing in this desk uses
that mechanism. It is there because **an absence and a decision look identical in a codebase**: a
reader who finds no delegation cannot tell whether it was rejected or never considered. A working
demonstration next to part 2.1's argument makes the answer unambiguous, and it goes red if a
framework upgrade changes how transfer behaves — which is exactly when the argument deserves
re-reading.

## The mechanism

The whole file, at `tests/test_cast.py`:

```python
"""Two agents: what each is allowed to do, what they cost together, and what delegation looks like.

The desk calls its two agents in a fixed order rather than letting a model decide who speaks next.
The last test in this file shows the framework's own delegation working, so that the choice not to
use it for a claim decision is a choice rather than an absence.
"""

from __future__ import annotations

import asyncio
import json
from collections.abc import AsyncGenerator
from contextlib import asynccontextmanager

import pytest
from google.adk.agents import Agent
from google.adk.models.base_llm import BaseLlm
from google.adk.models.llm_request import LlmRequest
from google.adk.models.llm_response import LlmResponse
from google.adk.runners import Runner
from google.adk.sessions import InMemorySessionService
from google.genai import types
from mcp import Client

from claims_desk import boundary, desk, sessions
from claims_desk.agents import classifier, letter_writer
from claims_desk.scripted import LETTERS, SCRIPTED_PREFIX
from claims_desk.util.budget import Budget, BudgetExceeded
from claims_mcp import tools
from claims_mcp.server import server


@pytest.fixture(autouse=True)
def _in_process(tmp_path, monkeypatch):
    monkeypatch.setattr(tools.store, "claims", tmp_path / "claims")
    monkeypatch.setattr(sessions, "service", InMemorySessionService())

    @asynccontextmanager
    async def connected():
        async with Client(server) as client:
            yield client

    monkeypatch.setattr(boundary, "connected", connected)
    return tmp_path


def test_the_cast_is_two_agents_with_different_remits() -> None:
    reader = classifier.build()
    writer = letter_writer.build()
    assert {reader.name, writer.name} == {"classifier", "letter_writer"}
    assert reader.model.model.startswith(SCRIPTED_PREFIX)
    assert writer.model.model.startswith(SCRIPTED_PREFIX)
    assert reader.model.model != writer.model.model


def test_neither_agent_is_allowed_to_decide_the_claim() -> None:
    assert "Do not decide whether the claim can be fast-tracked" in classifier.build().instruction
    assert "Do not promise a decision" in letter_writer.build().instruction


def test_the_letter_writer_is_told_it_has_no_figures() -> None:
    """It is not given the policy, the excess or the estimate, and the instruction says so."""
    instruction = letter_writer.build().instruction
    assert "You have not been given any" in instruction


def test_the_two_agents_do_not_share_a_conversation() -> None:
    """A session replays everything in it. The letter writer must not be given the call."""
    assert sessions.address("FNOL-4477") == "claim-FNOL-4477"
    assert sessions.address("FNOL-4477", "letter_writer") == "claim-FNOL-4477/letter_writer"

    description = "the flexible hose let go overnight"

    async def both() -> tuple[str, str]:
        budget = Budget(limit=3, label="FNOL-4477")
        await classifier.classify("FNOL-4477", description, budget)
        await letter_writer.write("FNOL-4477", "missing_photo_reference", budget)
        reading = await sessions.stored("FNOL-4477")
        writing = await sessions.stored("FNOL-4477", "letter_writer")
        return (_text_of(reading), _text_of(writing))

    reading_text, writing_text = asyncio.run(both())
    assert description in reading_text
    assert description not in writing_text
    assert "loss_type" not in writing_text


def _text_of(session) -> str:
    """Every word in a stored conversation, as one string."""
    out = []
    for event in session.events:
        if event.content and event.content.parts:
            out.extend(part.text or "" for part in event.content.parts)
    return "\n".join(out)


def test_a_deficiency_costs_two_calls_across_the_cast() -> None:
    """One budget, two agents. The breakdown names both."""
    queue = {n.id: n for n in desk.Store().notifications()}
    budget = Budget(limit=desk.CALLS_PER_NOTIFICATION, label="FNOL-4477")

    async def decide_and_write() -> None:
        verdict = await desk.decide(queue["FNOL-4477"], budget)
        await letter_writer.write(verdict.claim_id, verdict.reason, budget)

    asyncio.run(decide_and_write())
    assert budget.spent == 2
    assert budget.by == {"classifier": 1, "letter_writer": 1}


def test_the_budget_is_shared_so_one_agent_can_exhaust_the_other() -> None:
    budget = Budget(limit=1, label="one notification")
    asyncio.run(classifier.classify("FNOL-4471", "the flexible hose let go overnight", budget))
    with pytest.raises(BudgetExceeded) as raised:
        asyncio.run(letter_writer.write("FNOL-4477", "missing_photo_reference", budget))
    assert "letter_writer" in str(raised.value)


def test_the_letter_writer_refuses_a_reason_the_boundary_refuses() -> None:
    """It does not write a letter about a reason the department does not recognise."""
    out = asyncio.run(letter_writer.write("FNOL-4477", "no_photo", Budget(limit=3)))
    assert "error" in out
    assert "unknown reason" in out["error"]
    assert "letter" not in out


@pytest.mark.parametrize("reason", sorted(LETTERS))
def test_every_reason_produces_a_letter_naming_the_claim(reason: str) -> None:
    out = asyncio.run(letter_writer.write("FNOL-4477", reason, Budget(limit=3)))
    assert "FNOL-4477" in out["letter"]
    assert out["letter"].count(".") <= 4


def test_the_letter_is_stored_with_the_decision(_in_process) -> None:
    asyncio.run(desk.run_queue())
    records = [
        json.loads(path.read_text(encoding="utf-8"))
        for path in sorted((_in_process / "claims").glob("*.json"))
    ]
    assert len(records) == 12
    with_letter = [r for r in records if "letter" in r]
    assert len(with_letter) == 8
    assert all(r["outcome"] == "deficiency" for r in with_letter)
    assert all(r["claim_id"] in r["letter"] for r in with_letter)


def test_a_fast_track_may_not_carry_a_letter() -> None:
    """The boundary refuses it. A fast-track confirmation is not a deficiency letter."""
    refused = asyncio.run(
        boundary.call(
            "record_decision",
            {"claim_id": "FNOL-4471", "outcome": "fast-track", "letter": "anything"},
        )
    )
    assert refused["recorded"] is False
    assert refused["refused"] == "a fast-track has no letter"


class WantsToTransfer(BaseLlm):
    """A stand-in that asks to hand over on its first turn, then answers."""

    model: str = "scripted/wants-transfer"

    async def generate_content_async(
        self, llm_request: LlmRequest, stream: bool = False
    ) -> AsyncGenerator[LlmResponse, None]:
        sent = json.dumps([c.model_dump(exclude_none=True) for c in (llm_request.contents or [])])
        if "transfer_to_agent" in sent:
            yield LlmResponse(
                content=types.Content(role="model", parts=[types.Part(text="handed back")]),
                turn_complete=True,
            )
            return
        yield LlmResponse(
            content=types.Content(
                role="model",
                parts=[
                    types.Part(
                        function_call=types.FunctionCall(
                            name="transfer_to_agent", args={"agent_name": "specialist"}
                        )
                    )
                ],
            ),
            turn_complete=True,
        )


class Specialist(BaseLlm):
    model: str = "scripted/specialist"

    async def generate_content_async(
        self, llm_request: LlmRequest, stream: bool = False
    ) -> AsyncGenerator[LlmResponse, None]:
        yield LlmResponse(
            content=types.Content(
                role="model", parts=[types.Part(text="the specialist answered")]
            ),
            turn_complete=True,
        )


def test_the_framework_can_transfer_and_this_desk_chooses_not_to() -> None:
    """Delegation works. The desk's decision path does not use it, and that is a choice."""

    async def run_a_transfer() -> list[tuple[str, str | None, str]]:
        specialist = Agent(
            name="specialist",
            model=Specialist(),
            description="Handles the thing the front desk hands over.",
            instruction="Answer.",
        )
        front = Agent(
            name="front",
            model=WantsToTransfer(),
            description="Takes the call and hands over when it is not for them.",
            instruction="Hand over to the specialist.",
            sub_agents=[specialist],
        )
        runner = Runner(
            app_name="demo",
            agent=front,
            session_service=InMemorySessionService(),
            auto_create_session=True,
        )
        message = types.Content(role="user", parts=[types.Part(text="a question")])
        seen = []
        async for event in runner.run_async(user_id="u", session_id="s", new_message=message):
            text = ""
            if event.content and event.content.parts:
                text = "".join(p.text or "" for p in event.content.parts)
            seen.append((event.author, event.actions.transfer_to_agent, text))
        return seen

    seen = asyncio.run(run_a_transfer())
    authors = [author for author, _, _ in seen]
    assert authors == ["front", "front", "specialist"]
    assert seen[1][1] == "specialist"
    assert seen[-1][2] == "the specialist answered"
```

**Line by line:**

- **The fixture is day 6's and day 8's, combined** — a scratch claims directory, a fresh session
  service, and the transport swapped at `boundary.connected`. Three lines, and this is the third test
  file to carry them: the rep day 7 opened, which day 9 makes harder to keep ignoring.
- `assert {reader.name, writer.name} == {"classifier", "letter_writer"}` — **a set, so the test is
  about which agents exist rather than the order they were built in.**
- `assert reader.model.model != writer.model.model` — **two different doubles.** A single shared
  stand-in would make the two agents indistinguishable in a log, and this line is what would notice.
- `test_neither_agent_is_allowed_to_decide_the_claim` — **one assertion per agent, on prose**, the
  same brittle-on-purpose check day 7 introduced. These are the two sentences most likely to be
  softened, and softening either should be a conversation.
- `test_the_letter_writer_is_told_it_has_no_figures` — asserts on `"You have not been given any"`,
  the *factual* half of the prohibition. Part 1.1 argues that sentence does something the bare
  instruction does not, and this is what stops it being edited away.
- `assert sessions.address("FNOL-4477", "letter_writer") == "claim-FNOL-4477/letter_writer"` —
  **the separator is pinned by a test**, so the convention part 3.1 introduced cannot drift into two
  conventions.
- `budget = Budget(limit=3, ...)` then both agents — **the isolation test runs the real pair**, not a
  constructed session. A test that built the session by hand would prove something about the test.
- `reading = await sessions.stored("FNOL-4477")` and `writing = await sessions.stored("FNOL-4477",
  "letter_writer")` — **both threads, read back through the same function that wrote them.** This is
  why `stored` gained the parameter: without it the writing thread is unreachable and unassertable.
- `assert description in reading_text` — **the positive half first.** Without it, a bug that stored
  nothing anywhere would pass the negative assertions and look like isolation.
- `assert description not in writing_text` — **the assertion part 3.1 exists for.** The
  policyholder's words are in the conversation they were collected in, and in no other.
- `assert "loss_type" not in writing_text` — and the classifier's verdict is not there either. Two
  different leaks, two assertions, because a fix for one is not automatically a fix for the other.
- `def _text_of(session)` — a helper, defined **below its first use**, which Python permits because
  the name is resolved when the test runs rather than when the file is read. It sits next to the test
  that needs it rather than at the top of a file nobody scrolls to.
- `out.extend(part.text or "" for part in event.content.parts)` — `or ""` because **a part can hold a
  function call and no text**, and `None` in a `join` raises rather than failing the assertion you
  meant to make.
- `test_a_deficiency_costs_two_calls_across_the_cast` — **the day's central cost assertion.**
  `budget.spent == 2` and `budget.by == {"classifier": 1, "letter_writer": 1}`: the breakdown, not
  just the total, because a version that spent twice inside one agent would pass the first assertion.
- `Budget(limit=desk.CALLS_PER_NOTIFICATION, ...)` — **the constant, not a literal**, so raising the
  ceiling does not silently make this test weaker.
- `test_the_budget_is_shared_so_one_agent_can_exhaust_the_other` — a limit of **one**, spent by the
  classifier, and the letter writer refused. `assert "letter_writer" in str(raised.value)`: the
  refusal names the agent that was turned away, which is the whole value of `Budget.by`.
- `test_the_letter_writer_refuses_a_reason_the_boundary_refuses` — three assertions, and the third
  (`"letter" not in out`) is the one that matters: an implementation returning an error *and* a
  letter would satisfy the first two.
- `@pytest.mark.parametrize("reason", sorted(LETTERS))` — **eight tests from one function**, driven
  off the double's own table, `sorted` so they report in a stable order.
- `assert out["letter"].count(".") <= 4` — the instruction says four sentences at most, and this
  counts full stops. It would miss a five-sentence letter joined by a semicolon; it catches the
  ordinary way a wording grows.
- `test_the_letter_is_stored_with_the_decision` — **four assertions on the twelve files**: how many,
  how many carry a letter, that every letter belongs to a deficiency, and that each letter names its
  own claim. The last catches a loop that wrote one letter into every file.
- `test_a_fast_track_may_not_carry_a_letter` — the new refusal from part 1.2, asserted **through the
  boundary** rather than by calling the tool function, so the result envelope is exercised too.
- `assert refused["refused"] == "a fast-track has no letter"` — **equality, not substring**, because
  this message distinguishes one refusal from three others and a partial match would pass on the
  wrong one.
- `test_the_framework_can_transfer_and_this_desk_chooses_not_to` — **the test's name is the
  argument.** Both halves, so a reader scanning test names learns the decision without opening it.
- `assert authors == ["front", "front", "specialist"]` — **the three events in order**, the shape part
  2.1 walked through: the request, the handover, the work.
- `assert seen[1][1] == "specialist"` — `event.actions.transfer_to_agent` on the middle event, the
  field that says the conversation changed hands.
- `assert seen[-1][2] == "the specialist answered"` — the sub-agent's own text, proving it ran rather
  than the parent answering on its behalf.

## When it breaks

Give both agents the same stand-in — the obvious simplification, since one double could answer both
kinds of question:

```
>       assert reader.model.model != writer.model.model
E       AssertionError: assert 'scripted/claims-classifier' != 'scripted/claims-classifier'
```

The letters would still be written, the classifications would still be right, and every other test in
this file would pass. What is lost is in the logs: `"model": "scripted/claims-classifier"` on every
line, so a run's record no longer says which of the two agents produced which answer.

That is day 7's argument about the `scripted/` prefix, one level in. A double that cannot be told
apart from another double makes a transcript ambiguous — and the place it bites is the incident where
a letter was wrong and somebody needs to know whether the classification or the writing was at fault.

The smallest fix is two classes. It is more code than one, and the extra class exists entirely so
that a log line can be read.

## In production

**What a senior writes instead.** The same seam tests, with the isolation check generalised: not
"the description is absent from this agent's thread" but a sweep asserting that **no agent's thread
contains any field the agent was not given**, driven off a declared list per agent. This project
checks two strings on one pair, which is what catches today's leak and not tomorrow's.

**What degrades at scale.** Eleven test functions for two agents, most of them asserting that an
instruction contains a sentence. Five agents written this way is a file nobody reads. The shape that
survives is a **parametrised sweep over the cast** — every agent's model pinned, every name unique,
every instruction carrying its own prohibitions, every thread isolated — with per-agent tests only
for what is genuinely per agent, which here is the eight letters.

**The review comment.** *"This adds a third agent and no test in `test_cast.py` changed. Either the
cast assertion should have grown or the agent is not part of the cast — and if it is not, say in its
docstring what it is."*

**The interview question.** *"A bug shipped because an agent received input nobody passed it. Write
the test that would have caught it, and say why the tests you already had did not."*
