## One-line answer

Twenty-five tests, and most of them assert on **log records rather than return values** — which is
unusual, is the whole subject of the day, and is the only thing that stops an instrument going quiet
the way two of this project's log lines already had.

## The idea

Everything this day built produces output that nothing consumes.

That is not a criticism, it is the definition. A trace id, a span, a paging rule: none of them changes
what the desk decides, what the boundary writes, or what a policyholder receives. Take the whole of
today out and all 250 of yesterday's tests still pass, twelve claims are still decided identically, and
the only difference is that nobody can answer a question about it afterwards.

Which puts this file in an awkward position. The normal way to test something is to call it and assert
on what comes back, and the things worth asserting here do not come back — they go to standard error.
So nearly every test in this file captures stderr, parses the JSON lines out of it, and makes a claim
about what was written. `capsys`, `records(...)`, then an assertion about a field.

That is more fragile than testing a return value and it is the correct trade, for the reason part 3.2
demonstrated at this project's expense: **a log line nobody asserts on is a log line that can stop
saying anything without a single check going red.** `hooks.tool_result` emitted `<redacted>` for six
days. There was no failing test to write, because there was no test at all.

There is one more thing this file has to be careful about, and it is the reason for the `fresh`
fixture. The trace id and the span stack are `ContextVar`s, which means they are process state. A test
that starts a trace and does not clean up leaves that id set for every test that runs afterwards, and
the failures that produces are the worst kind — order-dependent, invisible when the file is run alone,
and blamed on whichever test happened to run second.

## The mechanism

The whole file, at `tests/test_observability.py`:

```python
"""One id across every hop, a span around everything that takes time, and rules about who is woken.

Most of these tests read log records rather than return values, which is unusual and is the subject:
a log line nobody asserts on is a log line that quietly stops saying anything, and this file exists
because day 17 found two that had.
"""

from __future__ import annotations

import asyncio
import json
import pathlib
import re
from contextlib import asynccontextmanager

import pytest
from google.adk.sessions import InMemorySessionService
from mcp import Client

from claims_desk import alerts, boundary, desk, sessions
from claims_desk.store import Store
from claims_desk.util import trace
from claims_desk.util.budget import Budget
from claims_desk.util.logging import log
from claims_mcp import tools
from claims_mcp.server import server

#: The project root, for the test that reads this desk's own source.
PROJECT = pathlib.Path(__file__).resolve().parent.parent


@pytest.fixture(autouse=True)
def _in_process(tmp_path, monkeypatch):
    monkeypatch.setattr(tools.store, "claims", tmp_path / "claims")
    monkeypatch.setattr(sessions, "service", InMemorySessionService())

    @asynccontextmanager
    async def connected():
        async with Client(server) as client:
            yield client

    monkeypatch.setattr(boundary, "connected", connected)
    return tmp_path


@pytest.fixture()
def fresh():
    """A trace that does not leak into the next test, and no span stack left standing."""
    token = trace.trace_id.set("")
    spans = trace.span_stack.set(())
    yield
    trace.trace_id.reset(token)
    trace.span_stack.reset(spans)


def records(captured: str) -> list[dict]:
    """Every JSON line in a captured stderr, and nothing else that happened to be on it."""
    found = []
    for line in captured.splitlines():
        try:
            found.append(json.loads(line))
        except json.JSONDecodeError:
            continue
    return found


# --- the correlation id ------------------------------------------------------------------------


def test_a_new_trace_is_readable_and_unique(fresh) -> None:
    first = trace.start()
    assert first.startswith("t-")
    assert len(first) == 14
    assert trace.start() != first


def test_a_trace_that_arrived_from_somewhere_is_adopted_not_replaced(fresh) -> None:
    """The boundary's whole job. A process handed an id must not invent its own."""
    assert trace.start("t-abcdef123456") == "t-abcdef123456"
    assert trace.current() == "t-abcdef123456"


def test_a_blank_arriving_trace_starts_a_new_one(fresh) -> None:
    """An empty environment variable is not an id, and reading one as an id joins unrelated work."""
    assert trace.start("").startswith("t-")
    assert trace.start("   ") != ""


def test_every_line_carries_the_trace_without_being_asked(fresh, capsys) -> None:
    """Fifty call sites became correlated without one of them being edited."""
    trace.start("t-111111111111")
    log("desk.decided", claim="FNOL-4477")
    line = records(capsys.readouterr().err)[0]
    assert line["trace"] == "t-111111111111"
    assert line["event"] == "desk.decided"


def test_an_untraced_line_carries_no_empty_fields(capsys) -> None:
    """A null on every line of an untraced run is noise that cannot be filtered out."""
    trace.trace_id.set("")
    trace.span_stack.set(())
    log("desk.decided", claim="FNOL-4477")
    line = records(capsys.readouterr().err)[0]
    assert "trace" not in line
    assert "span" not in line


def test_the_boundary_is_launched_with_this_desks_trace(fresh, monkeypatch) -> None:
    """The one mechanism that carries an id across a process line: the child's environment."""
    monkeypatch.delenv(boundary.ENDPOINT, raising=False)
    trace.start("t-222222222222")
    launch = boundary.target()
    assert launch.env[trace.TRACE_ENV] == "t-222222222222"
    assert launch.env["PATH"], "the child needs the rest of the environment too"


def test_a_url_boundary_carries_no_environment(fresh, monkeypatch) -> None:
    """An honest limit, asserted rather than discovered later: there is no child to hand it to."""
    monkeypatch.setenv(boundary.ENDPOINT, "http://boundary.invalid/mcp")
    trace.start("t-333333333333")
    assert boundary.target() == "http://boundary.invalid/mcp"


# --- spans -------------------------------------------------------------------------------------


def test_a_span_reports_its_name_its_parent_and_how_long_it_took(fresh, capsys) -> None:
    trace.start()
    with trace.span("queue"), trace.span("claim", claim="FNOL-4477"):
        pass
    inner, outer = records(capsys.readouterr().err)
    assert inner["span"] == "claim" and inner["parent"] == "queue"
    assert outer["span"] == "queue" and outer["parent"] is None
    assert inner["ms"] >= 0 and outer["ms"] >= inner["ms"]


def test_a_span_that_raises_is_still_logged_and_says_what_raised(fresh, capsys) -> None:
    """The spans that raise are the ones somebody is looking for."""
    trace.start()
    with pytest.raises(ValueError), trace.span("claim", claim="FNOL-4477"):
        raise ValueError("no")
    line = records(capsys.readouterr().err)[0]
    assert line["ok"] is False
    assert line["failed"] == "ValueError"


def test_a_span_reports_what_it_only_learned_at_the_end(fresh, capsys) -> None:
    trace.start()
    with trace.span("triage") as span:
        span["events"] = 2
    assert records(capsys.readouterr().err)[0]["events"] == 2


def test_the_span_stack_survives_a_failure(fresh) -> None:
    """A span that raises must not leave its name on every later line in the process."""
    trace.start()
    with trace.span("queue"):
        with pytest.raises(ValueError), trace.span("claim"):
            raise ValueError("no")
        assert trace.where() == "queue"
    assert trace.where() == ""


def test_a_claim_is_one_span_containing_every_hop(fresh, capsys) -> None:
    """The whole point of the id: one claim's work, from four modules, collected by one value."""
    note = {n.id: n for n in Store().notifications()}["FNOL-4477"]
    trace.start()
    with trace.span("claim", claim=note.id):
        asyncio.run(desk.decide(note, Budget(limit=5)))

    lines = records(capsys.readouterr().err)
    traces = {line["trace"] for line in lines if "trace" in line}
    assert len(traces) == 1, traces
    spans = [line["span"] for line in lines if line["event"] == "span"]
    assert "triage" in spans
    assert "boundary.call" in spans
    assert spans[-1] == "claim", "the outermost span closes last"


def test_a_boundary_call_is_timed_and_says_which_tool(fresh, capsys) -> None:
    trace.start()
    asyncio.run(boundary.fetch_policy("SYN-POL-1001"))
    call = [
        line
        for line in records(capsys.readouterr().err)
        if line["event"] == "span" and line["span"] == "boundary.call"
    ]
    assert len(call) == 1
    assert call[0]["tool"] == "fetch_policy"
    assert "fast_track_limit" in call[0]["fields"]


def test_the_field_list_is_not_called_keys(fresh, capsys) -> None:
    """Day 1's redactor matches `key` as a substring, so a field named `keys` is redacted whole.

    This test is the scar. Two log lines carried `<redacted>` for days because nobody read them.
    """
    trace.start()
    asyncio.run(boundary.fetch_policy("SYN-POL-1001"))
    for line in records(capsys.readouterr().err):
        for name, value in line.items():
            assert value != "<redacted>", f"{line['event']}.{name} says nothing"


# --- who gets woken ------------------------------------------------------------------------------


def test_every_rule_says_why() -> None:
    """A rule whose justification nobody wrote is a rule that pages somebody for nothing."""
    for rule in alerts.RULES:
        assert set(rule) == {"event", "level", "why"}
        assert rule["level"] in {alerts.PAGE, alerts.TICKET, alerts.COUNT}
        assert rule["why"]
    for burst in alerts.BURSTS:
        assert 0 < burst["share"] <= 1
        assert burst["why"]


def test_exactly_one_event_pages_on_its_own() -> None:
    """If everything is a page, nothing is. The bar is: there is an action and waiting is worse."""
    pages = [rule["event"] for rule in alerts.RULES if rule["level"] == alerts.PAGE]
    assert pages == ["desk.boundary_refused"]


def test_every_rule_names_an_event_this_desk_actually_logs() -> None:
    """A rule for an event nobody emits will never fire, and reads as though it might.

    The scan is a regex over every source file rather than a list kept by hand, because a list
    kept by hand is what goes stale, and staleness is the thing this test is for.
    """
    emitted: set[str] = set()
    for source in (PROJECT / "claims_desk").rglob("*.py"):
        emitted.update(
            re.findall(r'log\(\s*"([a-z_.]+)"', source.read_text(encoding="utf-8"))
        )
    assert "desk.decided" in emitted, "the scan itself found nothing"
    for rule in (*alerts.RULES, *alerts.BURSTS):
        assert rule["event"] in emitted, rule["event"]


def test_an_unclassified_event_is_a_ticket_and_not_silence() -> None:
    assert alerts.level_for("desk.something_invented_next_week") == alerts.TICKET


def test_a_clean_run_wakes_nobody() -> None:
    quiet = [{"event": "desk.decided"}] * 12 + [{"event": "desk.queue_finished"}]
    assert alerts.summarise(quiet, claims=12)["level"] == alerts.COUNT


def test_one_held_claim_is_a_ticket_and_not_a_page() -> None:
    """The gate firing is the system working. Paging for it teaches people to ignore pages."""
    run = [{"event": "desk.decided"}] * 12 + [{"event": "desk.awaiting_approval"}]
    assert alerts.summarise(run, claims=12)["level"] == alerts.TICKET


def test_one_refused_write_pages_immediately() -> None:
    """No threshold, no burst. One is enough, because nothing is being recorded."""
    decision = alerts.summarise([{"event": "desk.boundary_refused"}], claims=12)
    assert decision["level"] == alerts.PAGE
    assert "processed into nothing" in decision["reasons"][0]


def test_one_escalation_is_counted_and_a_quarter_of_the_queue_is_a_page() -> None:
    one = [{"event": "desk.provider_unavailable"}]
    assert alerts.summarise(one, claims=12)["level"] == alerts.COUNT
    three = [{"event": "desk.provider_unavailable"}] * 3
    assert alerts.summarise(three, claims=12)["level"] == alerts.PAGE


def test_a_burst_threshold_is_a_share_so_it_survives_a_bigger_queue() -> None:
    """Three escalations in twelve is an outage; three in four hundred is a Tuesday."""
    three = [{"event": "desk.provider_unavailable"}] * 3
    assert alerts.summarise(three, claims=400)["level"] == alerts.COUNT


def test_a_page_says_what_it_counted() -> None:
    """A page that does not carry its numbers is a page somebody reproduces by hand at 3am."""
    run = [{"event": "desk.boundary_refused"}, {"event": "desk.decided"}]
    decision = alerts.summarise(run, claims=12)
    assert decision["counts"] == {"desk.boundary_refused": 1, "desk.decided": 1}


def test_the_whole_queue_is_a_ticket_and_not_a_page(_in_process, capsys) -> None:
    """The real thing, end to end: twelve claims, one held, and nobody woken up."""
    counts = asyncio.run(desk.run_queue())
    decision = alerts.summarise(records(capsys.readouterr().err), claims=sum(counts.values()))
    assert decision["level"] == alerts.TICKET
    assert decision["reasons"] == []
    assert decision["counts"]["desk.awaiting_approval"] == 1
```

**Line by line:**

- **The docstring says the file's method and its reason in two sentences.** Somebody arriving here
  needs to know within ten seconds why these tests read stderr rather than return values, or they will
  "improve" the file into something that tests nothing.
- `fresh` **is a fixture that resets both `ContextVar`s and is not `autouse`.** Not automatic, on
  purpose: the tests that do not take it are the ones asserting behaviour *outside* a trace, and having
  to ask for a clean trace makes the ones that need one visible in their signature.
- `token = trace.trace_id.set("")` **then `reset(token)`**, rather than setting it back to a
  remembered value. `ContextVar` tokens are the supported way to undo a `set`, and they restore
  whatever was there before including "nothing was ever set", which a manual assignment cannot.
- `records(captured)` **skips lines that are not JSON**, with a `try`/`except`. This is not defensive
  padding: ADK's own telemetry writes plain-text warnings to the same stream — *Skipping missing token
  usage metadata for agent classifier* — and a parser that raised on them would make every test that
  runs an agent fail for an unrelated reason.
- `test_a_new_trace_is_readable_and_unique` asserts `len(first) == 14` — **`t-` plus twelve.** A
  length assertion is normally a smell; here the length is the design decision (short enough to read
  over the telephone), so it is the thing worth pinning.
- `test_a_trace_that_arrived_from_somewhere_is_adopted_not_replaced` — **the whole cross-process
  mechanism in two lines.** If `start` invented a new id when given one, the boundary's lines would
  carry a different trace from the desk's and the two would never join.
- `test_a_blank_arriving_trace_starts_a_new_one` covers `""` **and** `"   "`. An environment variable
  set to the empty string is not absent, and it is the realistic way this arrives — a shell script that
  exports a variable it failed to compute.
- `test_every_line_carries_the_trace_without_being_asked` — **the payoff test.** `log("desk.decided",
  claim=...)` is a call written on day 6, unmodified, and it now emits a `trace` field.
- `test_an_untraced_line_carries_no_empty_fields` asserts **absence**: `"trace" not in line`. Not
  `line["trace"] == ""`. The design decision is that the field is omitted, and a test that accepted an
  empty string would pass on the version that writes `"trace": null` on every line of every untraced
  run.
- **That test does not take `fresh`** and sets the context vars in its body instead, because it is
  specifically about the state where nothing has been set — worth doing explicitly where a reader can
  see it.
- `test_the_boundary_is_launched_with_this_desks_trace` asserts the trace **and** `launch.env["PATH"]`,
  the second with a message. Part 1.2's failure is exactly that second assertion, and without it the
  boundary subprocess would fail to start for reasons several layers away from the cause.
- `test_a_url_boundary_carries_no_environment` — **a test for what the mechanism cannot do.** Worth
  writing precisely because the limit is invisible: switch to HTTP and the traces silently stop joining
  up, with nothing failing.
- `test_a_span_reports_its_name_its_parent_and_how_long_it_took` unpacks `inner, outer` **in that
  order**, which asserts the ordering as a side effect: the inner span's line is written first, because
  spans close from the inside out.
- `assert outer["ms"] >= inner["ms"]` — **a relationship rather than a value.** Timing tests that
  assert absolute durations are flaky by construction; this one says the only thing that must always be
  true.
- `test_a_span_that_raises_is_still_logged_and_says_what_raised` — **the `finally` clause, tested.** The
  spans that raise are the ones somebody is searching for at three in the morning, and a span that only
  logged on success would be missing from exactly those traces.
- `test_the_span_stack_survives_a_failure` asserts `trace.where()` **after** the raise, at two depths.
  Without the reset in the `finally`, a failed span would leave its name on every subsequent line in
  the process, and every later log line would be attributed to a span that ended long ago.
- `test_a_claim_is_one_span_containing_every_hop` — **the day's thesis as one assertion**: `len(traces)
  == 1` over every line four modules and a subprocess produced. And `spans[-1] == "claim"`, because the
  outermost span must close last or the nesting is wrong.
- `test_a_boundary_call_is_timed_and_says_which_tool` asserts `"fast_track_limit" in call[0]["fields"]`
  — which is also, quietly, a second check on day 16's projection: a `fields` list containing
  `risk_address` would be that day's leak visible in a log line.
- `test_the_field_list_is_not_called_keys` — **part 3.2's scar.** It asserts no field of any line is the
  redaction marker, rather than asserting anything about `keys`, so it catches the next collision
  rather than only the one that has already happened.
- `test_every_rule_says_why` and `test_exactly_one_event_pages_on_its_own` — **the same shape as day
  16's threat-model tests**, for the same reason. The second does not claim one page is correct; it
  claims that changing the set is a conversation.
- `test_every_rule_names_an_event_this_desk_actually_logs` **scans the source with a regex** rather than
  keeping a list, and asserts `"desk.decided" in emitted` first — a guard on the scan itself, so a
  regex that silently matches nothing fails loudly instead of passing vacuously.
- `test_an_unclassified_event_is_a_ticket_and_not_silence` pins the direction of the default. Silence
  for an unclassified event is the choice that makes a new event invisible for five releases.
- `test_a_clean_run_wakes_nobody` — **the control.** Without it, a `summarise` that returned `TICKET`
  for everything would pass the two tests either side. It is also the test that caught the first
  version of this module, which did exactly that.
- `test_one_escalation_is_counted_and_a_quarter_of_the_queue_is_a_page` and
  `test_a_burst_threshold_is_a_share_so_it_survives_a_bigger_queue` — **the same three escalations,
  twice**, against twelve claims and against four hundred. One pages, one does not. That pair is the
  entire argument for a share rather than a count, expressed as two assertions.
- `test_a_page_says_what_it_counted` asserts the `counts` dictionary by equality, because a page that
  does not carry its evidence is one somebody reproduces by hand while half asleep.
- `test_the_whole_queue_is_a_ticket_and_not_a_page` — **the real thing, end to end**, and the assertion
  that matters most in the alerting half of this file: a system that never says "nothing happened
  tonight" is one nobody will believe when it says something did.

## When it breaks

Make the `fresh` fixture `autouse=True`, which looks like a tidy-up — every test gets a clean trace,
nobody has to remember to ask:

```diff
-@pytest.fixture()
+@pytest.fixture(autouse=True)
 def fresh():
```

Everything passes. The file is greener, shorter in its signatures, and one test now proves nothing:
`test_an_untraced_line_carries_no_empty_fields` is the one test in the file whose subject is the
*absence* of a trace, and it was written without the fixture on purpose. With `autouse`, its own setup
does what the test was checking, so it passes whether or not `log` omits empty fields — and the day
somebody makes `log` write `"trace": null`, this file stays green and every line of every untraced run
carries a null.

That is a general hazard of `autouse` fixtures and it is worth naming: **a fixture that establishes a
precondition for every test disarms the tests whose subject is that precondition.** The smallest fix is
to leave `fresh` opt-in. The habit that catches it is asking, of every fixture you make automatic,
which test in the file is about the thing the fixture guarantees.

## In production

**What a senior writes instead.** Most of this file, plus one thing it has no way to do: a test that
runs the queue and asserts the trace is **well-formed as a tree** — every span's `parent` names a span
that was open at the time, no orphans, no cycles. That is the invariant a tracing library gives you for
free and a hand-rolled span stack does not, and it is the one that breaks first when somebody adds a
span inside an `asyncio.gather`.

**What degrades at scale.** Asserting on captured stderr works because this project writes a few
hundred lines per run. A service writing a hundred thousand lines a run cannot have its tests parse
them, and the shape that survives is a test-only sink — a log handler that appends records to a list —
with the JSON serialisation itself tested once, separately. The assertions stay the same; only the
capture changes.

**The review comment.** *"`records()` swallows every line that is not JSON, which is right for ADK's
warnings and wrong as a general policy — a malformed record written by this project's own `log` would
also be silently skipped, and this file would be green. Count what you skipped and assert it is only
the lines you expect."*

**The interview question.** *"How do you test that your service logs the right thing? And then: how
would you find out whether any of your existing log lines have stopped saying anything?"*
