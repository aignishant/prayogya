## One-line answer

Seventeen tests hold the four promises the rest of this desk will be built on, and the way you
learn whether they hold anything is to break the code on purpose and watch `./run check` go red —
which this day did four times on purpose and once by accident, on its own test file, before the
first green.

## The idea

The kit cage has a bench beside it, and every scanner goes across the bench before it goes out.
Power on, scan the test barcode taped to the bench, read the count on the screen: it should say
one. It takes a few seconds and it almost always says one — and the one morning it says zero, or
says nothing, is the morning the bench paid for every other morning, because that scanner would
have counted an aisle.

The bench is not a test of the scanner. It is a test of the *test*. A bench with no barcode on it,
where the counter just looks at the scanner and says "seems fine", is a bench that has never once
said no, and a check that has never said no is a green light with no wire behind it. This desk's
kit — four modules and a registry — was written this day, and every one of them makes a promise
that is invisible when kept: the key is never printed, a log line hides a secret and nothing that
is not one, a retry waits what it was told to wait and then gives up, a budget refuses, the
registry refuses. Kept promises produce no output. The only way to know the promises are enforced
rather than described is to break each one and watch a specific line go red.

So this part is the bench. It writes the seventeen tests, runs the gate green, and then breaks the
code five ways — a line that is one character too long, a redactor that matches substrings, a
retry that ignores what the provider asked for, a registry that agrees with everything, and a file
whose last line was deleted by a careless edit — reading the real red each time. One of the five
was not planned. The first `./run check` of this day was red on the test file's own line length,
and that is in the transcript below exactly as it happened, because a day whose gate only ever went
red on purpose is a day that has not met the gate.

## The mechanism

The whole file, at `tests/test_kit.py`:

```python
"""The kit, tested before anything uses it.

Every test here can go red. Between them they hold the four promises the rest of this desk will
be built on: the key is never printed, a log line carries no secret and hides nothing that is not
one, a retry waits what it was told to wait and then escalates, and a budget refuses instead of
overspending.
"""

from __future__ import annotations

import pytest

from stock_desk import models
from stock_desk.util import keys
from stock_desk.util import logging as desk_logging
from stock_desk.util.backoff import Transient, delays, retry
from stock_desk.util.budget import Budget, BudgetExceeded


def test_require_names_the_variable_and_quotes_no_value(monkeypatch: pytest.MonkeyPatch) -> None:
    monkeypatch.setenv("GOOGLE_API_KEY", "")
    with pytest.raises(keys.MissingKey) as raised:
        keys.require("GOOGLE_API_KEY")
    assert "GOOGLE_API_KEY" in str(raised.value)


def test_load_env_leaves_the_platform_alone(tmp_path, monkeypatch: pytest.MonkeyPatch) -> None:
    env_file = tmp_path / ".env"
    env_file.write_text("GOOGLE_API_KEY=from-the-file\n", encoding="utf-8")
    monkeypatch.setenv("GOOGLE_API_KEY", "from-the-platform")
    assert keys.load_env(env_file) == []
    assert keys.require("GOOGLE_API_KEY") == "from-the-platform"


def test_fingerprint_is_stable_and_is_not_the_secret() -> None:
    tag = keys.fingerprint("AIzaSy-not-a-real-key")
    assert tag == keys.fingerprint("AIzaSy-not-a-real-key")
    assert len(tag) == 12
    assert tag not in "AIzaSy-not-a-real-key"


def test_log_redacts_by_field_name_at_any_depth() -> None:
    record = desk_logging.log(
        "bin.read",
        bin="C-07-2",
        api_key="AIzaSy-not-a-real-key",
        provider={"name": "test-double", "auth_token": "also-not-real"},
    )
    assert record["bin"] == "C-07-2"
    assert record["api_key"] == desk_logging.REDACTED
    assert record["provider"]["auth_token"] == desk_logging.REDACTED
    assert record["provider"]["name"] == "test-double"


@pytest.mark.parametrize(
    ("name", "secret"),
    [
        ("api_key", True),
        ("apiKey", True),
        ("provider.key", True),
        ("AUTHORIZATION", True),
        ("keys", False),
        ("monkey", False),
        ("keyword", False),
        ("tokens_used", False),
    ],
)
def test_redaction_matches_whole_words_and_not_substrings(name: str, secret: bool) -> None:
    """A field that lists a dictionary's keys must not be blanked for containing k-e-y."""
    assert desk_logging.looks_secret(name) is secret


def test_delays_double_and_stop_one_short_of_the_attempts() -> None:
    assert list(delays(attempts=4, base=1.0)) == [1.0, 2.0, 4.0]
    assert list(delays(attempts=1)) == []


def test_retry_prefers_the_interval_the_provider_asked_for() -> None:
    waited: list[float] = []
    attempts = {"n": 0}

    def flaky() -> str:
        attempts["n"] += 1
        if attempts["n"] < 3:
            raise Transient("429 from the ledger", retry_after=7.5)
        return "52"

    assert retry(flaky, attempts=4, sleep=waited.append) == "52"
    assert waited == [7.5, 7.5]


def test_retry_escalates_rather_than_inventing_a_quantity() -> None:
    def always_busy() -> str:
        raise Transient("429 from the ledger")

    with pytest.raises(Transient):
        retry(always_busy, attempts=3, sleep=lambda _: None)


def test_budget_refuses_and_says_who_spent_what() -> None:
    budget = Budget(limit=4, label="count of bin C-07-2")
    for who in ("supervisor", "counter", "reconciler", "replenisher"):
        budget.spend(who)
    assert budget.remaining == 0
    with pytest.raises(BudgetExceeded) as raised:
        budget.spend("reconciler")
    assert "reconciler" in str(raised.value)
    assert "count of bin C-07-2" in str(raised.value)


def test_registry_refuses_an_alias_and_the_legacy_default() -> None:
    assert models.pinned(models.PRIMARY) == "gemini-3.8-flash"
    with pytest.raises(models.UnpinnedModel):
        models.pinned("gemini-flash-latest")
    with pytest.raises(models.UnpinnedModel):
        models.pinned(models.LEGACY)
```

**Line by line:**

- **The docstring names the four promises**, in the words the modules use, so that a reader who
  opens this file first knows what a red line here means: a promise the rest of the desk relies on
  has stopped being kept.
- `from stock_desk.util import logging as desk_logging` — **renamed on import**, because a test
  module that binds the name `logging` shadows the standard library's, and the first `import
  logging` somebody adds to this file later would get the desk's instead. The alias is the cheaper
  of two surprises.
- `test_require_names_the_variable_and_quotes_no_value` — **the message contains the name and
  the test checks for the name.** With `monkeypatch.setenv(..., "")` the variable exists and is
  empty, which is the state a half-filled `.env` produces; `require` must treat empty as missing.
  What the test does *not* assert is that the value is absent from the message — there is no value
  to leak here — and that gap is the `TODO(me)` at the end of this part.
- `test_load_env_leaves_the_platform_alone` — **the file loses to the environment.** A `.env` on
  disk says `from-the-file`; the process was started with `from-the-platform`; `load_env` returns
  `[]` — it set nothing — and `require` reads the platform's. This is the promise that lets a
  container or a pipeline inject the key without a file on any developer's laptop being able to
  override it.
- `test_fingerprint_is_stable_and_is_not_the_secret` — **three properties of a fingerprint**:
  the same input gives the same tag, the tag is twelve characters, and the tag is not a substring
  of the secret. The third is the one that matters: a "fingerprint" that was the first twelve
  characters of the key would satisfy the first two.
- `test_log_redacts_by_field_name_at_any_depth` — **a record two levels deep**, with a secret at
  the top and one inside a nested dictionary, and a plain field beside each. Four assertions: two
  that secrets became `<redacted>`, two that non-secrets did not. A redactor that blanked the
  whole nested dictionary would pass the third assertion and fail the fourth.
- `@pytest.mark.parametrize` **with eight names** — **the redactor's rule, as a table.** Four
  names that must be redacted, spelt four ways (`api_key`, `apiKey`, `provider.key`,
  `AUTHORIZATION`), and four that must not — `keys`, `monkey`, `keyword`, `tokens_used` — each of
  which *contains* a secret word as letters and none of which *is* one. The docstring says which
  failure this table exists to prevent: a field that lists a dictionary's keys going blank for
  containing k-e-y. Each row is its own test with its own name in the report, which is what makes
  the failure below say `[keys-False]` rather than "the redactor test".
- `test_delays_double_and_stop_one_short_of_the_attempts` — **the schedule, and the edge.** Four
  attempts is three waits, doubling; one attempt is no waits at all. The second assertion is the
  one that catches an off-by-one in `range`.
- `test_retry_prefers_the_interval_the_provider_asked_for` — **`sleep=waited.append`**: the sleep
  function is replaced by a list's `append`, so the test records what the retry *would* have waited
  without waiting it. Two failures with `retry_after=7.5`, then success; the list must read
  `[7.5, 7.5]` and not the schedule's `[1.0, 2.0]`. This is the test that goes red below when the
  provider's interval is ignored.
- `test_retry_escalates_rather_than_inventing_a_quantity` — **the give-up.** Three attempts, all
  busy, and the `Transient` reaches the caller. What the test asserts by its shape is what the
  desk must never do: return a quantity when the ledger did not give one.
- `test_budget_refuses_and_says_who_spent_what` — **four agents, four calls, and the fifth
  refused.** The message must name the agent that asked and the unit of work it was for, so that a
  refused count in a log says which bin and which agent rather than only that a limit was hit.
- `test_registry_refuses_an_alias_and_the_legacy_default` — **one echo and two refusals**, and it
  is the test that turns part 3.1's registry from a promise into a gate. The alias and the legacy
  ID are the two refusals with their own messages; the catch-all is exercised by both when the
  specific lines are removed, which is why the first experiment in part 3.1 stayed green.

## When it breaks

The fifth break is the one nobody plans. This day's author, restoring `budget.py` after an
experiment, ran a one-line shell edit meant to remove a stray line from the end of the file — and
removed the wrong one. The file ended like this:

```

    def remaining(self) -> int:
```

Paths shortened; everything else verbatim. Not a failed test — an *error during collection*, which
is worse and better at once. Worse because zero tests ran: the report says `1 error`, not `16
passed`, and a reader skimming for a count would find none. Better because it is impossible to
miss. The kit's import is the first thing the test file does, and a module that cannot be imported
takes every test down with it, loudly. The smallest fix was `git checkout -- stock_desk/util/budget.py`,
which is the fix for every careless edit to a file the history holds — and the habit is that a
file is restored from the history, not retyped from memory, because memory is what removed the
line.

## In production

**What a senior writes instead.** The same seventeen tests, plus one that fails when a promise is
added without a test: a check that every public function in `stock_desk/util/` is named somewhere
in `tests/`, so that the fifth module somebody adds on day 12 cannot ship untested by forgetting.
And the gate run by the pipeline on every push, so that "did you run `./run check`" is never a
question a reviewer has to ask.

**What degrades at scale.** Seventeen tests in a tenth of a second. A distribution centre's stock
system carries four desks, twelve services and forty thousand tests, and the gate takes twenty
minutes — at which point people run the tests for the module they changed and let the pipeline run
the rest, and the redactor's substring bug lives in a log for a week because the only test that
would catch it belongs to a module nobody changed. The bench works because every scanner crosses
it; a bench that only the scanners somebody is worried about cross is a bench that finds nothing.

**The review comment.** *"`test_require_names_the_variable_and_quotes_no_value` asserts the name
is in the message. It does not set a value and check that the value is *absent* from the message
— which is the promise in the test's own name. Add a case with a non-empty variable and a failure
mode that raises, and assert the value is not in `str(raised.value)`."*

**The interview question.** *"You have a test suite that has been green for a month. Tell me how
you would find out whether it tests anything, and what you would do about the tests that turn out
not to."*
